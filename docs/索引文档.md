# DSCODE 文档索引

> 本文件是 DSCODE 全部文档的入口与导航。任何"我应该看哪份文档"的问题从这里开始。
> 维护原则：新增文档必须在此登记一行；文档改名/合并必须同步更新本索引。

---

## 如何使用本索引

1. 按你关心的问题在"快速定位"找关键词 → 跳到对应文档。
2. 不确定就看"文档总览"的"读者"列判断该文档是否你需要的。
3. 每份原理文档专注一个核心机制，"原理类"按主题组织，"工程类"按交付物组织。

## 维护规约

1. **新增文档**：在"文档总览"加一行，并视情况在"快速定位"加关键词行。
2. **拆分原理文档**：先在"待立项的原理文档"记录拆分触发条件；满足后再拆并迁移内容。
3. **重命名/合并**：全局搜引用，同步更新本索引与所有指向。
4. **过时文档**：不直接删，先在 todos-list 标 DEPRECATED 项，待无引用后移除并在 done 归档说明。

---

## 命名约定

- 工程类：`<主题>文档.md`（架构文档、需求文档、成功标准、todos-list、todos-done、索引文档）。
- 原理类：`原理-<主题>.md`，主题用英文短词（agentloop / compact / plan-and-execute / file-tools / web-search / mcp / session / provider / permission / extension / tui），便于排序与检索；沙盒执行沿用中文主题（原理-沙盒执行.md）。
